# Contraya — working rules

**Read `STATUS.md` first** — it is the source of truth for current state, next steps, and gotchas.

- The product is the **Expo/React Native app in `mobile/`** (iOS + Android). The web app at the repo root is the marketing landing only (no web dashboard, ever).
- Contraya is Warraya's sibling (same owner, same stack, same conventions). When in doubt about a pattern, the Warraya repo is the reference implementation.
- **Builds go through Xcode, never the terminal:** Claude runs `npx expo prebuild --platform ios` (that is the ONLY build-adjacent command Claude suggests), owner opens `mobile/ios/Contraya.xcworkspace` (Team: Renovatio, LLC), Runs or Archives. Metro runs separately via `npx expo start`. **Never suggest `eas build`, `eas submit`, `expo run:ios`, `expo run:android`, or any `xcodebuild` invocation** — `expo run:*` compiles through the terminal and bypasses this workflow just as much as EAS does. Never hand-edit `ios/` — prebuild regenerates it from `app.config.ts`.
- Shell env for `mobile/` work on the owner's Mac: `export PATH="/opt/homebrew/opt/node@22/bin:$PATH"` and `export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8`. Never `npm dedupe`.
- Checks: `cd mobile && npm run typecheck && npm test`. Landing: `npm run build` at repo root. Edge functions: `deno check supabase/functions/*/index.ts` (added 2026-07-30; the repo gates never covered Deno before and two functions carried latent type errors).
- Supabase: owner runs `supabase db push` (has the password); Claude writes migrations + can deploy edge functions. Explicit GRANTs in every migration (default privileges are unreliable under db push).
- "Commit" always means commit AND push. **Session-end invariant:** no session ends with a dirty tree; `git status` clean and pushed is part of "done".
- **"But the file exists" rule** (from the 2026-07-29 logo incident): when the owner says a file exists and git disagrees, the first hypothesis is an UNTRACKED file in the Mac working copy, not a git mystery. Ask for an `ls` or a Finder screenshot of the folder and hand them exact `git add` + `commit` + `push` commands BEFORE doing any history archaeology. The web uploader's missed second "Commit changes" step and an untracked local file look identical from git's side.
- **Mac pickup ritual** — run after any remote session pushes `mobile/` changes (remote sessions cannot touch the Mac's gitignored `ios/`, `node_modules`, or `.env`): `cd ~/Developer/sppa/contraya && git pull origin main && cd mobile && npm install && npx expo prebuild --platform ios && open ios/Contraya.xcworkspace`, then build IN Xcode (⌘R / Archive). Quit Xcode first if it has the stale workspace open.
- **Typed-routes gotcha (burned 2026-07-30):** `.expo/types/router.d.ts` is gitignored and per-machine, and **prebuild does NOT regenerate it** — only `npx expo start` does. After pulling commits that add or rename screens, `npm run typecheck` can fail with "not assignable to parameter" route errors that look like code bugs but are stale typegen. Fix: boot `npx expo start` briefly (kill it once it's up), then re-run typecheck. Also keep `ios/.xcode.env.local` pinned to `/opt/homebrew/opt/node@22/bin/node` — prebuild rewrites it to a brew Cellar-VERSIONED path that dies on the next brew upgrade (the Mac-wide gotcha).
- Copy rules: **say "AI" plainly.** (Rule reversed 2026-07-29 by the owner. This is legally sensitive, so hiding the mechanism behind the mascot was the wrong trade. Contry is still the character; the copy now says Contry "uses AI to read your contract and explain it".) Every legal string lives in exactly one place, `mobile/src/lib/legal.ts` — never hand-write a disclaimer at a call site. Three claims travel together on every analysis surface: it uses AI, it is not legal advice, and **using Contraya creates no attorney-client relationship and no attorney-client privilege**. "Built by lawyers, for everyday people" is approved positioning (owner's call, 2026-07-29; pluralized 2026-08-11 at the owner's correction, made against advice: a bare credential claim naming no jurisdiction of licensure is treated as attorney advertising by several bars). Flagged for the pre-launch attorney review; do not expand on it or add a name; **legal-conclusion questions get no yes and no no** — "can I sue/evict/win/is this legal" is always answered with "that is a question for a licensed attorney" plus what the contract itself says, quoted, and the answer never bends toward what the asker wants to hear; **describe, never advise** — every analysis surface states what the contract SAYS, never what the user should do, and carries `DISCLAIMER` from `legal.ts`; no em dashes; support email is hello@usecontraya.com — never a personal address.
- RevenueCat entitlement id is exactly `premium`. Public keys live in `mobile/.env` (gitignored) — never commit keys.
- Free tier: 2 analyses LIFETIME (`FREE_ANALYSIS_LIFETIME_LIMIT`); premium 10 analyses/month (`PRO_MONTHLY_ANALYSES`) + 40 Ask Contry questions/month (`PRO_MONTHLY_CHATS`, chat is premium-only) at **$9.99/mo or $69.99/yr with a 3-day free trial** (owner decision 2026-07-30, priced against measured token cost — the math lives in `mobile/src/lib/limits.ts`; raising a quota reopens it). Server ceilings 20 analyses + 60 questions/month in the edge functions (paid limits are client-side only, so the ceilings are the real cost gate until server-side receipt validation ships). An analysis costs ~$0.15-0.50 in tokens; a chat question ~$0.02-0.30 depending on document size.
- **Name Anthropic, never a euphemism** (added 2026-08-23 after the 5.1.1(i)/5.1.2(i) rejection of 1.0 (6)). The AI provider is `AI_PROVIDER` in `legal.ts` and it appears in the consent sheet, Settings AI and Your Data, About These Summaries, the privacy policy and the store listing. "A third-party document-processing service provider" is the exact phrasing that got the app rejected. Every path that sends a document to the model goes through `ensureAiConsent()` first (`lib/AiConsentContext`), the edge functions 403 without a consent record, and `__tests__/aiConsentGate.test.ts` fails the build if a new call site skips the gate. Never write an absolute claim like "never shared" about documents. **Two consents, two surfaces:** accepting the Terms (the tick on welcome/signin, `components/TermsAgreement` + `lib/terms.ts`) is NOT permission to send a document to Anthropic, and neither may be reworded to cover the other. `__tests__/termsGate.test.ts` fails if the terms copy so much as says "AI", because a diff that merges them would look perfectly reasonable.
- **Never claim "end-to-end encryption"** in any copy or store listing. Server-side analysis requires the server to read the document, so E2EE would be a false claim. Correct claims: encrypted in transit and at rest, private storage only you can access, delete everything anytime.
